# Data Structures in Python

A simple Python practice project implementing core data structures from scratch.

## Included Data Structures

- `single_linked_list.py` — Singly linked list (`LinkedList`)
- `double_linked_list.py` — Doubly linked list (`DoubleLinkedList`)
- `stack.py` — Stack (LIFO)
- `queue.py` — Queue (FIFO)
- `hashmap.py` — Hash map using buckets and a custom hash function
- `binary_search_tree.py` — Binary search tree (`BinarySearchTree`) with in/pre/post-order traversal
- `heap.py` — Min-heap (`MinHeap`) with heapify and meld
- `trie.py` — Prefix trie (`Trie`) with autocomplete support
- `graph.py` — Graph (`Graph`) using adjacency list, BFS and DFS (directed/undirected)

## Features

- Basic operations for each structure (insert/add/remove/get/etc.)
- Time complexity notes in code comments
- Small runnable demos in each file under `if __name__ == "__main__":`
## Requirements

- Python 3.8+ (no third-party dependencies)

## Run Examples

Run any module directly:

```bash
python single_linked_list.py
python double_linked_list.py
python stack.py
python queue.py
python hashmap.py
python binary_search_tree.py
python heap.py
python trie.py
python graph.py
```

### Learning Goal: 
This repository is intended for understanding how common data structures work internally, without relying on built-in Python containers for implementation logic.
